daml.tmLanguage.json is the TextMate grammar of the Daml VS Code extension, converted
from plist XML to JSON. Source: repository digital-asset/daml (https://github.com/digital-asset/daml),
file sdk/compiler/daml-extension/syntaxes/daml12.tmLanguage.xml, commit
c69d4fdda3fb132aeb06a52562ea51f91171a53d. The only change is that applyEndPatternLast, an
integer flag in the plist, is the boolean that JSON grammars use. The grammar is licensed
as follows.
